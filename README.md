# Moore Consultants website

The official Moore Consultants website is deployed at https://www.mooreconsultants.com.au/.

## Deployment

Production is deployed through the Moore Consultants Vercel project `test_mooreconsultants` from this repository.

## Email enquiries

Website contact enquiries are sent to gmoore@mooreconsultants.com.au using Resend. Set `RESEND_API_KEY` as a protected environment variable in Vercel.
